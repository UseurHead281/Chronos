# Chronos 📸

**Chronos 0.25** — приложение «фото дня»: один день, один момент, сохранённый локально на телефоне.

## Что нового в 0.25
- Более аккуратный Material 3 интерфейс и пустые состояния
- Надёжнее сохранение подписей к фотографиям
- Сохранение настройки вида галереи
- Улучшенный поиск по датам и подписям
- Улучшенная сортировка снимков по дате
- Статистика: фото, серии, месяц и год
- Последние 35 дней в виде календаря активности
- Избранное, удаление с подтверждением и полноэкранный просмотр
- Тёмная/светлая/системная тема и цветовой акцент
- Ежедневные напоминания с выбранным временем и текстом
- Выбор фронтальной/основной камеры

## Версия
`0.25.0+25`

## Сборка
Проект собирается через GitHub Actions. При создании тега вида `v0.25` workflow собирает `Chronos.apk` и прикрепляет его к GitHub Release.
