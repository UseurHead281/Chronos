⏳ Chronos

«A minimal daily journal for your memories.»

Chronos — приложение для сохранения фотографий, мыслей и моментов из повседневной жизни.

Beta • Android • Flutter

---

✦ Features

- 📸 Daily memories — сохраняйте события и фотографии
- 📝 Notes — короткие записи о вашем дне
- 🔔 Reminders — локальные уведомления
- 🎨 Customization — персонализация интерфейса
- 🎙️ Voice notes — голосовые заметки
- 🔤 Custom fonts — выбор шрифта
- 🖼️ App icons — смена иконки прямо в приложении
