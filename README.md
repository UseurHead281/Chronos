⏳ Chronos

«Сохраняй моменты. Возвращайся к ним.»

Chronos — минималистичное приложение для сохранения личных воспоминаний: фотографий, мыслей, заметок и моментов из повседневной жизни.

Android • Flutter • Beta

---

💭 Идея

Chronos создаётся вокруг простой мысли:

«Некоторые моменты хочется сохранить не потому, что они важные, а потому что они твои.»

Это не социальная сеть, не планировщик и не очередное приложение с десятками ненужных функций.

Chronos — это личное пространство для воспоминаний, которое постепенно превращается в историю твоей жизни.

Главный принцип проекта:

минимум лишнего → максимум внимания воспоминаниям.

---

🔒 Безопасность и приватность

Личные воспоминания должны оставаться личными.

Chronos развивается с учётом этого принципа:

- 🔐 минимум ненужных разрешений;
- 📱 данные должны оставаться под контролем пользователя;
- 🚫 никакой социальной ленты;
- 🚫 никакой необходимости делиться воспоминаниями;
- 🛡️ безопасность личных данных — один из приоритетов дальнейшей разработки.

По мере развития проекта система хранения данных будет дополнительно улучшаться.
