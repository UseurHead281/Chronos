# Хронос (Chronos)
# Фото дня 📸

Android-приложение на Flutter: каждый день в выбранное время приходит напоминание сделать фото. Снимки хранятся локально на телефоне.

## Возможности
- Ежедневное push-напоминание в заданное время
- Одно фото в день, можно переснять
- Стрик: дни подряд, рекорд и общее число фото
- Галерея всех снимков с просмотром и удалением
- Настройки: время и текст напоминания, камера, тема, цвет акцента
- Дизайн Material 3

## Сборка
- Приложение собирается через GitHub Actions:
> 1. Откройте `app-release.apk` из releases
