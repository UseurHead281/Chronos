### ✦ Что такое Chronos?

**Chronos** — минималистичное мобильное приложение для сохранения одного момента каждого дня. 

* **Ничего лишнего:** без перегруженного интерфейса и сложных настроек.
* **Фокус на главном:** только день → фотография → воспоминание.

> *«Один день — один кадр».*

---

### 🎨 Идея и философия

Chronos создаётся вокруг простой мысли: **время проходит слишком быстро, чтобы не сохранять моменты**. Приложение постепенно превращается в визуальную историю вашей жизни — день за днём.

Это не попытка сделать ещё одну социальную сеть. Это ваш **маленький цифровой архив**, свободный от чужого мнения и лишнего контента.
* Меньше шума.
* Больше моментов.
