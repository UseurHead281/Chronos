Chronos

«Chronos — приложение для сохранения повседневных моментов, фотографий и воспоминаний в одном месте.»

Chronos создан как простой личный дневник, в котором каждый день можно сохранить не только текст, но и фотографии, заметки и другие небольшие фрагменты воспоминаний.

Проект находится в стадии Beta и активно развивается. Интерфейс, функции и внутренняя архитектура ещё могут изменяться.

О проекте

Chronos — небольшой экспериментальный проект, посвящённый идее цифрового дневника.

Главная задача приложения — сделать сохранение воспоминаний максимально простым.

Вместо сложных систем планирования и большого количества лишних функций Chronos концентрируется на самом главном:

«открыл → сохранил момент → вернулся к нему позже.»

Приложение разрабатывается на Flutter, поэтому основная часть интерфейса и логики написана на Dart.

Проект пока находится в Beta, поэтому некоторые функции могут работать нестабильно, а интерфейс может меняться между версиями.

---

Основная идея

В повседневной жизни множество небольших моментов быстро забываются.

Фотография, короткая мысль, событие или обычный день могут спустя несколько месяцев оказаться важной частью воспоминаний.

Chronos пытается превратить такие моменты в небольшую личную историю.

Основные принципы

- Простота — приложение не должно заставлять пользователя разбираться в десятках меню.
- Минимализм — интерфейс не должен отвлекать от самого содержимого.
- Персонализация — пользователь должен иметь возможность настроить приложение под себя.
- Приватность — личные воспоминания должны оставаться личными.
- Архив воспоминаний — старые записи должны быть удобны для просмотра.
- Постепенное развитие — новые функции добавляются без превращения приложения в перегруженный комбайн.

Возможности

Текущие возможности Chronos развиваются вместе с проектом.

Дневник

Chronos позволяет сохранять ежедневные записи и возвращаться к ним позже.

Запись может стать небольшой заметкой о конкретном дне, событии или мысли.

Фотографии

Одной из основных идей приложения является сохранение фотографий вместе с воспоминаниями.

Это позволяет использовать Chronos не только как текстовый дневник, но и как визуальный архив.

Даты

Записи привязаны ко времени, поэтому воспоминания можно воспринимать как историю, которая постепенно формируется день за днём.

Уведомления

В проекте используется система локальных уведомлений Flutter.

Она предназначена для того, чтобы помогать пользователю не забывать о дневнике.

Настройка приложения

Chronos постепенно получает больше возможностей персонализации.

Одно из направлений развития — возможность менять внешний вид приложения непосредственно из настроек.

Голосовые заметки

Ещё одно направление "v0.9" — голосовые заметки.

Помимо обычного текста пользователь сможет сохранить короткую аудиозапись.

Например:

"Сегодня был очень странный день..."

Вместо того чтобы печатать такую запись, её можно будет просто записать голосом.

Возможный сценарий

1. Открыть создание записи.
2. Нажать кнопку записи.
3. Записать голосовую заметку.
4. Остановить запись.
5. Сохранить её вместе с воспоминанием.
6. Позже открыть запись и прослушать аудио.

Голосовые записи особенно полезны для моментов, когда гораздо проще сказать мысль, чем печатать её.

Установка

Требования

Для локальной разработки потребуется:

- Flutter SDK;
- Dart SDK;
- Android SDK;
- Git;
- Android Studio или другая совместимая среда разработки.

Проверить установку Flutter можно командой:

flutter doctor

---

Клонирование репозитория

Склонируйте репозиторий:

git clone https://github.com/UseurHead281/Chronos.git

Перейдите в директорию проекта:

cd Chronos

---

Установка зависимостей

После клонирования проекта выполните:

flutter pub get

Flutter загрузит зависимости, указанные в "pubspec.yaml".

---

Запуск

Для запуска приложения на подключённом Android-устройстве или эмуляторе:

flutter run

Перед запуском убедитесь, что устройство отображается в списке:

flutter devices

---

Сборка Android

Для создания APK можно использовать:

flutter build apk

Готовый APK обычно находится в:

build/app/outputs/flutter-apk/

Для release-сборки:

flutter build apk --release

Иконки приложения

Если используется генерация launcher icon через Flutter, команда:

dart run flutter_launcher_icons

После изменения конфигурации иконки рекомендуется выполнить:

flutter clean
flutter pub get
dart run flutter_launcher_icons

Затем снова собрать приложение.

Принцип развития

Chronos не стремится добавлять функции просто ради количества.

Новая функция должна отвечать хотя бы одному из вопросов:

«Делает ли она сохранение воспоминаний удобнее?»

«Делает ли она приложение более персональным?»

«Делает ли она просмотр старых воспоминаний интереснее?»

«Делает ли она использование Chronos проще?»

Если ответ отрицательный, функция не обязательно должна попадать в приложение.

---

Приватность

Chronos предназначен для хранения личных воспоминаний.

При разработке проекта важно учитывать, что записи, фотографии и голосовые заметки могут содержать личную информацию.

Поэтому дальнейшее развитие приложения должно учитывать:

- безопасность пользовательских данных;
- предсказуемое хранение файлов;
- отсутствие ненужной передачи данных;
- понятное поведение приложения;
- контроль пользователя над своими воспоминаниями.
