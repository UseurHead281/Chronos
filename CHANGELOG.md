# Изменения

## v0.9.0 — Beta

- Полностью приведена структура Flutter-проекта к стандартной `lib/`.
- Добавлены плавные переходы между разделами.
- Улучшены появления карточек, фото и элементов календаря.
- Добавлены более мягкие press-анимации.
- Сохранены Hero-переходы для фотографий.
- Добавлена нативная смена launcher-иконки `icon1`–`icon6` на Android.
- Иконки перенесены в `assets/icons/`.
- GitHub Actions теперь проверяет проект через `flutter analyze` перед сборкой APK.
